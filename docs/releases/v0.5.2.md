# IMS-DMS 0.5.2

Beschriftungen, Eingaben, Hilfetexte und Fehlermeldungen mehrspaltiger Formulare
haben gemeinsame Zeilen. Dadurch bleiben nebeneinanderliegende Felder auf gleicher
Höhe, auch wenn eine Beschriftung umbricht oder nur ein Feld einen Hilfetext hat.

- Einheitliche Höhen für Text-, Datums-, Datei- und Auswahlfelder.
- Ausgerichtete Filter und Filterbuttons in der Dokumentenübersicht.
- Gleiche Ausrichtung in den SMTP-Einstellungen.
- Auf kleinen Bildschirmen werden die Felder weiterhin untereinander dargestellt.
- Für Touchgeräte bleiben die größeren Bedienelemente erhalten.

Browserprüfungen vergleichen Position und Höhe der Eingaben auf Desktop und Tablet,
auch mit absichtlich mehrzeiligen Beschriftungen.

Update als root:

```sh
curl -fsSL https://raw.githubusercontent.com/Schello805/Dms_sie/v0.5.2/scripts/install_linux.py -o /tmp/install-ims-dms.py
python3 /tmp/install-ims-dms.py --update --ref v0.5.2
```
