# IMS-DMS 0.5.3

## Workflowkorrektur

Eigene QMB-Uploads werden weiterhin direkt freigegeben; eigene Entwürfe und Revisionen
werden ausdrücklich über den Freigabebereich veröffentlicht.

Eine bereits eingereichte eigene Fassung konnte bisher nach einer späteren QMB-Zuordnung
festhängen: Die Direktfreigabe erwartete einen Entwurf, die normale Entscheidung sperrte
Selbstfreigaben. Jetzt kann der verantwortliche QMB auch diese Fassung ausdrücklich freigeben.

- Eigene offene Freigaben erscheinen in der QMB-Aufgabenliste und Glocke sowie mit
  „Jetzt freigeben“ in der Tabelle.
- Der ursprüngliche Prüfzyklus wird geschlossen und unverändert aufbewahrt.
- Ein neuer QMB-Direktfreigabezyklus erhält einen eigenen Nachweis; bestehende
  Entscheidungen werden weder überschrieben noch gelöscht.
- Vor der Übernahme wird der Fingerabdruck des eingereichten Inhalts geprüft.
- Die gesamte Aktion ist atomar. Bei einem Fehler bleibt der ursprüngliche Zyklus offen.
- Zusätzliche QMB-Bemerkungen zur Direktfreigabe werden im Änderungsprotokoll gespeichert.
- Eine fehlende Prüfinstanz bei einer Übernahme führt zu einer verständlichen Validierung.

Autoren ohne QMB behalten den unabhängigen Prüfablauf. Eine Ablehnung benötigt weiterhin
eine Bemerkung und gibt die Fassung zur Überarbeitung zurück. Die periodische Überprüfung
bleibt unabhängig vom Ersteller. Deaktivierte Dokumente müssen vor einer Bearbeitung
reaktiviert werden. Bestehende Dokumente werden durch das Update nicht automatisch freigegeben.

## Update als root

```sh
curl -fsSL https://raw.githubusercontent.com/Schello805/Dms_sie/v0.5.3/scripts/install_linux.py -o /tmp/install-ims-dms.py
python3 /tmp/install-ims-dms.py --update --ref v0.5.3
```
