# IMS-DMS 0.5.0

## Fachliche Änderung

Aktive QMBs geben eigene Uploads direkt frei, unabhängig davon, ob ein alter Client noch
„Entwurf“ übermittelt. Datei, Metadaten und Normzuordnungen werden vor der Freigabe gespeichert.
Die Gültigkeitsdauer beginnt mit der Freigabe und folgt der Kategorie. Es entsteht ein eigener,
unveränderlicher Direktfreigabenachweis einschließlich Akteur, QMB-Qualifikation und Fingerprint.

Eigene QMB-Revisionen werden nach dem Bearbeiten über „Änderungen direkt freigeben“ veröffentlicht.
Normale Autoren verwenden weiterhin Entwurf → QMB-Prüfung → Freigabe/Ablehnung. Eine QMB-Rolle
erlaubt keine Direktfreigabe fremder Entwürfe. Alte Entscheidungen und Dokumentstände bleiben
unverändert; vorhandene Entwürfe werden nicht pauschal durch eine Migration freigegeben.

## Qualität und Wartbarkeit

- GitHub-Workflow für PostgreSQL-Anwendungstests, JavaScript-Regressionen, statische Prüfungen
  und echte Chromium-Browsertests auf Desktop- und Tablet-Größe; Fehlertraces und Screenshots
  werden als CI-Artefakte bereitgestellt. Browserläufe laufen auf isolierten CI-Runnern.
- Gemeinsame Berechtigungsprojektion für die Oberfläche, pro Request wiederverwendet.
  Datenbank- und Mutationsprüfungen bleiben zusätzlich bestehen; keine rollenabhängigen
  Dokumentinhalte in gemeinsamem Cache.
- Dienste in Katalog, Dokumente, Workflow und Zugriff aufgeteilt; die bisherige API bleibt
  über `services.py` als Kompatibilitätsfassade erhalten.
- Gemeinsame CSS-Variablen für Farben/Steuergeometrie und entfernte übersteuerte Headerregeln.
- Ein vollständiger Katalog-SELECT statt zwei im normalen Seitenabruf. Ungültige/entfernte
  Seiten werden kontrolliert aufgelöst. `ims-dms-manage profile_catalog BENUTZER` liefert
  einen EXPLAIN-ANALYZE-Bericht ohne Dokumentinhalte oder Zugangsdaten.

## Installieren / Aktualisieren

Das Installationsskript aus dem Release-Tag laden und als root ausführen:

```bash
curl -fsSL https://raw.githubusercontent.com/Schello805/Dms_sie/v0.5.0/scripts/install_linux.py -o /tmp/install-ims-dms.py
python3 /tmp/install-ims-dms.py --update --ref v0.5.0
```

Der Installer sichert vor Migration 0022. Kein automatisches Zurückrollen von Datenbankmigrationen.
Ein Rückweg erfordert die zusammengehörige Datenbank-/Dateisicherung und den passenden alten
Quellstand. IP/DHCP-Einstellungen werden nicht verändert. Systemupdates bleiben separat möglich.
