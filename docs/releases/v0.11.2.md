# 0.11.2 – Einheitliche Darstellung der Module

Die unterschiedliche Größe von Logo, Navigation, Überschrift und Footer zwischen
Dokumentenübersicht und Prozessen wurde vereinheitlicht. Die kompakte Kopf- und Fußzeile
wird gemeinsam gepflegt; beide Module verwenden dieselben Größen und Bildschirmgrenzen.
Die Prozessansicht bleibt innerhalb der Bildschirmhöhe. Auf Tablets bleibt der Kontoname
sichtbar; auf kleinen Smartphones steht er im Kontomenü.

Der Diagrammzoom bleibt unabhängig vom Seitenzoom. Es wird kein Browserzoom erzwungen.
Ein Browserregressionstest vergleicht Schriftgrößen und Kopf-/Logohöhe zwischen beiden
Modulen auf Desktop und Tablet. Die bestehenden Smartphone- und Workflowtests bleiben erhalten.

Keine Datenbankmigration erforderlich. Update als root:

```bash
curl -fsSL https://raw.githubusercontent.com/Schello805/Dms_sie/v0.11.2/scripts/install_linux.py -o /tmp/install-ims-dms.py
python3 /tmp/install-ims-dms.py --update --ref v0.11.2
```
